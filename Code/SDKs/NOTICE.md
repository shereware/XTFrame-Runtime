## Vendored vs. fetched

- **Vendored** (source committed under `Code/SDKs/`, unmodified): doctest, stb, nlohmann/json,
  SheenBidi, libunibreak, bc7enc_rdo (bc7enc/bc7decomp/rgbcx). See `Code/SDKs/README.md` and each subdirectory's `VERSION.txt` for
  exact commit/tag and source URL.
- **Fetched at configure time** via CMake `FetchContent` (pinned tags or archive hashes in
  `Code/SDKs/versions.cmake`, built from source, never installed system-wide) into
  `Code/SDKs/_fetched/<name>/`, shared by every build tree (`Tools/CMake/xt_sdks.cmake`;
  `XT_SDK_OFFLINE=ON` never downloads): FreeType and HarfBuzz (`Tools/CMake/xt_text_deps.cmake`), SDL2
  (`Tools/CMake/xt_sdl2.cmake`), Clipper2 (`Tools/CMake/xt_clipper2.cmake`; only `Clipper2Lib`'s engine, offset
  and rectclip sources are compiled), cpp-httplib (`Tools/CMake/xt_httplib.cmake`, header only) and miniz
  (`Tools/CMake/xt_miniz.cmake`, only `miniz.c`).
- **Test-only assets** (not linked into any library or tool): the Noto font subsets under
  `Tests/fonts/`, OFL-licensed; see `Tests/fonts/README.md` for how they were produced and their
  per-file registered family names.
