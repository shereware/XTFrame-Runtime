# XTFrame 編輯器術語表（UI 用語統一）

> 2026-10-09 草案（使用者要求：「列一張術語表，一份描述性解說，來統一 xt editor 介面上的東西」）。狀態：**待使用者審閱**；審閱後成為 UI 字串、設計文件、AI 契約與 Editor Service 文件的用語依據。本表只定「叫什麼」與「指什麼」；行為規格仍在各章（17、25～32）。

## 1. 原則

1. **一個概念一個詞**。同一個東西在面板標題、選單、屬性欄、工具提示、設計文件、AI 契約（29 章）、Editor Service op 名稱裡用同一個中文詞與同一個英文詞。
2. **美術語言在前，技術名在後**。面板上用美術看得懂的詞（圖層、片段、關鍵幀）；技術名（element、`<use>`、`@keyframes`）只在「進階」開關下或原始碼面板出現。
3. **名稱就是 id**（26 §26.1.1）。圖層名稱、UI 名稱、符號名稱、連接點名稱都是程式與 AI 的契約，不另有「顯示名稱」。
4. **中英固定對照**。英文字串是 `Code/Editor/I18n/xtframe_editor_en.ts` 的 source，中文是 `zh-TW.ts` 的翻譯；本表第 2 節的對照就是這兩個檔的規範。
5. **三層檔案詞彙不動**（22 §22.11.1）：UI Project、UI、Bundle 三個詞在 UI 與文件中原樣使用，不翻譯、不換字（所以「套件瀏覽器」要改回「Bundle 瀏覽器」）。
6. 面板與分頁標題用名詞；選單與按鈕用動詞開頭；工具名一律「○○工具」；狀態詞（一般、滑過、按下…）不加「狀態」兩字。

## 2. 術語表

每列：**中文（UI 用）** · 英文（source 字串／API） · 定義 · 容易混淆的鄰居。

### 2.1 專案與檔案

| 中文 | 英文 | 定義 | 不要混用 |
|---|---|---|---|
| UI Project | UI Project | 可編輯的來源：一個資料夾，根檔 `<名稱>.xtui`，內含多個 UI、`shared/`、`contracts/`。編輯器唯一能開來改的東西。 | 不叫「專案」單獨出現時可省 UI；不叫「bundle」。 |
| UI | UI | 一個畫面：`<ui>/<ui>.xt` 加同名 `.xts`、`.xtflow`、sidecar。UI 清單面板列的就是它。 | 不叫「文件」「頁面」「場景」。 |
| Bundle | Bundle | 發佈產物，唯讀：`manifest.json` + 編譯後的 IR + 素材。遊戲與宿主插件只讀它。 | 不叫「套件」「封包」；宿主自有的容器格式不屬於本倉。 |
| 只在編輯器顯示 | editor-only | 元素屬性：編輯器畫布看得到、發佈與展示空間裡沒有（03 §3.13）。給 HUD 墊底的遊戲截圖、參考圖用 | 不叫「隱藏」（隱藏是 `display: none`，兩邊都看不到） |

| 文件 | document | 一個 UI 的 `.xt` 原始檔在編輯器內的模型（17 §17.2）。UI 是面板上的詞，文件是講檔案與 API 時的詞。 | 面板上盡量說 UI。 |
| 樣式表 | stylesheet | `.xts`：樣式規則、設計變數、`@timeline`、觸發所在。 | 不叫「CSS」。 |
| 流圖 | flow | `.xtflow`：資料邏輯的節點圖。分「UI 流圖」（一個 UI 一份）與「全域流圖」（`bundle.xtflow`）。 | 面板標題統一「流圖」，不用「流程圖」。 |

| 設計變數 | token | `.xts` 裡的 `--名稱` 變數：顏色、數值、字型、文字。 | 英文 UI 字串統一 Token；中文不叫「變數」「token」混用。 |
| 主題 | theme | 一組設計變數值的集合（深色／淺色…），執行時可切換。 | — |
| 設計文件（設計系統 part） | design document (design system part) | UI Project 的第 6 個 part：原則、用語、決策等文字條目與由全部 part 生成的 `design/DESIGN.md`（30 §30.2、35 章）。UI 字串用「設計文件」。 | 不叫「設計系統空間」「設計系統面板」；設計系統不是獨立概念。 |
| 色彩庫 | palette | 這個專案用的顏色的集合（`design/palette.yaml`），每個是一張色票，分群組（品牌、中性、稀有度…）。是人與 AI 共用的參考知識，不是變數；設計變數可記錄「來自哪張色票」。 | 不叫「調色盤」「色盤」。 |
| 色票 | swatch | 色彩庫裡的一個顏色：名稱、值、角色、來源、狀態。 | 不叫「色樣」。 |
| 參考 | reference | 佐證用的圖像、影片、文件或網址，放 `design/references/`，可加區域註解與連結；不出貨。 | 不叫「參考資料」「素材」（素材會出貨，參考不會）。 |
| 集合 | collection | 素材的分組 = 資料夾（`shared/img/<集合>/`）；標籤另外自由加。 | 不叫「資料夾」（美術用語）。 |
| 佔位 | placeholder | 從參考升格、尚未換成正式素材的狀態；發佈時是錯誤。 | — |
| 存檔點 | checkpoint | 人取名的歷史節點，帶縮圖與說明；可回到它（36 章）。 | 不叫「tag」「版本」。 |
| 主線 | main | 正式進度那條線。 | 不叫「master」「主分支」。 |
| 方案 | variant | 從某處分出去做的另一條路線；採用併回主線，不採用就留著直到整理。 | 不叫「分支」。 |
| 採用／比較／整理方案 | adopt / compare / prune | 方案的三個動作：併回主線、並排看差異、刪除沒採用的。 | 不叫「merge」「diff」「刪分支」。 |
| 自動存檔記錄 | autosave record | 每次存檔一筆，平常收起。 | 不叫「commit」。 |
| 筆記 | note | 內建的文字閱讀與編輯元件（35 §35.16）所顯示的內容。 | 不叫「Markdown」。 |
| 決策記錄 | decision | 一條設計決定的紀錄（情境、決定、後果、狀態），`design/text/decisions/`。 | 不叫「ADR」。 |
| 語言 | language | 文字的翻譯集（`strings/<lang>.csv`）；語言列可切換預覽語言。 | — |
| 效果範本 | effect template | `.xtfxp`：可重複套用的效果堆疊（含動畫）。 | 不叫「模板」。 |
| 契約 | contract | `contracts/`：給 AI 的情境規格與節制規格（25 §25.6、29 章）。 | — |
| sidecar | sidecar | `<ui>.xteditor.json`：編輯器狀態（可見、鎖定、色標、收合），不進 Bundle。 | UI 上不出現；文件用原詞。 |
| IR | IR | `.xtir`：編譯後的二進位，Bundle 內容。 | UI 上只在訊息與瀏覽器出現。 |
| 烘焙 | bake | 把編輯期才有的東西（修改器、向量動畫）轉成執行時格式；`.xtcl` 是烘焙出的動畫檔。 | 不叫「輸出」「轉換」。 |
| 發佈 | publish | UI Project → Bundle。 | 不叫「匯出」「打包」；「匯出」保留給 SVG／Lottie 等外部格式。 |
| 匯入 | import | 外部格式（Figma、Lottie、SVG、Claude Design）→ UI Project 內容。 | — |

### 2.2 畫布與圖層

| 中文 | 英文 | 定義 | 不要混用 |
|---|---|---|---|
| 畫布 | canvas | 中央的編輯區：舞台 + 文件區 + 尺標 + 裝置工具列。 | 不叫「預覽」（預覽是畫布裡那張即時畫面）。 |
| 舞台 | stage | 畫布上文件區以外的灰底。 | — |
| 文件區 | document area | 畫布上 UI 本身的範圍（邏輯解析度，17 §17.4.1）。 | — |
| 裝置框 | device frame | 以裝置長寬比畫出的外框；安全區、出血是它的疊層。 | — |
| 圖層 | layer | 文件樹的一個元素在美術面前的樣子：名稱 + 角色圖示 + 可見／鎖定。圖層 = 元素，一對一。 | 美術語言用「圖層」；API、原始碼面板、設計文件講結構時用「元素」。不叫「物件」「節點」。 |
| 元素 | element | 圖層在文件樹與核心裡的技術名（`<div>`、`<img>`…）。 | 見上。 |
| 名稱 | name | 圖層的 id，`[A-Za-z][A-Za-z0-9_]*`，文件內唯一；改名 = 重構。 | 不另叫「id」（進階顯示例外）、不叫「標籤」。 |
| 角色 | role | 由標籤與樣式推導的圖層類型與圖示：文字、圖片、向量、群組、堆疊、按鈕、輸入、實例、片段、外部、攝影機、3D、清單、粒子。 | 不叫「類型」（類型留給連接點與素材）。 |
| 群組 | group | 自由容器：子圖層以 `left/top` 自由擺放。 | 工具列的「自由容器」= 群組；建議工具列也改用「群組」。 |
| 堆疊 | stack | flex 容器：子圖層依序排列（水平／垂直／網格）。 | 工具列的「堆疊容器」= 堆疊。與「效果堆疊」無關。 |
| 標籤 | tag | 給圖層或 UI 加的分類字（搜尋與篩選用）。 | 不是 HTML 標籤名；HTML 標籤名在 UI 上叫「標籤名」且只在進階顯示。 |
| 版面 | layout | 圖層的位置與尺寸規則：自由（`left/top`）或堆疊內的排列；屬性面板的「版面」分組。 | 不叫「佈局」。 |
| 外觀 | appearance | 填色、描邊、不透明度、圓角、混合模式；屬性面板的「外觀」分組。 | — |
| 選取 | selection | 畫布或圖層面板上目前選中的圖層集合。 | — |
| 把手 | handle | 選取框四邊八點，以及向量頂點的貝茲把手。前者叫「縮放把手」，後者叫「把手」。 | — |
| 原點 | origin | 圖層自己的變換中心（transform-origin）；轉成符號時的九宮格原點。 | 不叫「錨點」。 |
| 錨點 | anchor | 3D 面板的 anchor 與「錨點對齊路徑」中的錨點：圖層放到路徑上時的對齊點。 | 與原點分開用。 |
| 參考線／格線／吸附 | guides / grid / snap | 畫布輔助。 | — |
| 範圍 | scope | 一條時間軸能驅動的圖層集合：文件根、一個符號定義、一個片段各是一個範圍。 | — |
| 進入編輯 | Edit in Place | 雙擊實例或片段進入其範圍編輯（父層變暗）；麵包屑回上層。 | 不叫「就地編輯」「編輯符號」。 |

### 2.3 符號

| 中文 | 英文 | 定義 | 不要混用 |
|---|---|---|---|
| 符號 | symbol | 可複用的定義：自己的圖層、樣式、時間軸、狀態、連接點。放在本檔或共用符號庫。 | 不叫「元件」「組件」「prefab」。 |

| 覆寫 | override | 實例上與符號定義不同的屬性值；可「取消覆寫」。 | 不叫「覆蓋」。 |
| 分離實例 | detach instance | 把實例變回普通圖層。 | — |
| 轉成符號 | convert to symbol | 把選取的圖層變成符號定義 + 一個實例。 | — |

| 標準符號庫 | standard library | 隨產品附的符號（30 §30.4），專案可覆寫。 | 專案面板的「規範」區改名「標準」。 |
| 插槽 | slot | 符號定義裡讓實例填內容的位置。 | — |
| 變體 | variant | 符號的具名狀態集（尚未實作，保留詞）。 | — |

### 2.4 向量

| 中文 | 英文 | 定義 | 不要混用 |
|---|---|---|---|
| 向量圖層 | vector layer | 一個 `<svg>` 圖層，內含形狀子圖層。 | — |
| 形狀 | shape | 向量圖層內的一個子圖層：路徑、矩形、橢圓、線、多邊形／星形。 | 不叫「圖形」。 |
| 路徑 | path | 由頂點與把手構成的曲線（`<path d>`），形狀的一種；「轉為路徑」= 把參數形狀變成可編輯路徑。 | **只指向量幾何**。動畫用的叫「運動路徑」，檔案系統的叫「檔案路徑」。 |
| 運動路徑 | motion path | 圖層沿著某條路徑移動的動畫（「沿路徑」命令）。 | 與「路徑」分開用；畫布上顯示時標「運動路徑」。 |
| 頂點 | vertex | 路徑上的點；類型：角點、平滑、對稱、自動。 | 不叫「節點」「錨點」。 |
| 頂點工具 | Vertex Tool | 編輯頂點與把手的工具（現名 Node Tool，建議改名）。 | 「節點」留給流圖。 |
| 輪廓 | contour | 路徑裡一段連續的頂點序列（開放或閉合）。 | — |
| 填色／描邊 | fill / stroke | 形狀的兩種外觀。 | 不叫「填充」「邊框」（邊框 border 是圖層盒的）。 |
| 造形指令 | shape operations | 聯集、減去、交集、排除、分割、外框化描邊、簡化、位移路徑、平面化（破壞式）。 | — |
| 修改器 | modifier | 非破壞式的形狀運算元素（trim、repeat、round、offset…），可動畫；可烘焙。 | 不叫「效果」（效果是像素層）。 |
| 描圖 | trace | 點陣圖 → 向量（「描圖轉向量」）。 | — |
| 轉為外框 | convert to outlines | 文字 → 向量形狀。 | 與「外框化描邊」（描邊 → 填色形狀）分開。 |
| 網格 | mesh | 圖片的變形網格（圖釘拉動）。 | — |
| 圖釘 | pin | 網格上的控制點。 | — |
| 骨骼／骨架 | bone / skeleton | 32 章：骨骼是一根，骨架是整組。 | — |
| 蒙皮 | skin | 形狀或網格的頂點跟隨骨骼的權重。 | — |
| 約束 | constraint | 骨骼的 IK／旋轉／彈簧等規則。 | 與圖層的「版面約束」（左右置中縮放）同字不同物；UI 上後者寫「版面約束」。 |
| 鏡射 | symmetry | 繪製時的對稱複製（垂直／水平／四向）。 | 不叫「對稱」（對稱是頂點類型）。 |

### 2.5 動畫

| 中文 | 英文 | 定義 | 不要混用 |
|---|---|---|---|
| 時間軸 | timeline | 一個範圍內的一條具名動畫（`@timeline intro`）：長度、標記、每個圖層的軌道。一個範圍可有多條。 | 「時間軸面板」是面板；「時間軸」是資料。 |
| 軌道 | track | 一個圖層的一個屬性在時間軸上的關鍵幀序列；圖層列摺疊時顯示聚合軌。 | — |
| 關鍵幀 | keyframe | 軌道上一個時間點的值。**統一「關鍵幀」**，不用「關鍵影格」。 | — |
| 幀 | frame | 時間的顯示單位（依 fps）；內部仍是秒。「幀率」= fps。 | 不用「影格」「影格率」。 |
| 播放頭 | playhead | 時間軸上目前時間的指標。 | — |
| 標記 | marker | 時間軸上的具名時間點，觸發與宿主可跳到它。 | — |
| 音效提示 | sound cue | 時間軸音效軌上的時間點 + cue 名稱；宿主播放。 | 不叫「音效」「音軌」。 |
| 緩動 | easing | 兩個關鍵幀之間的速度曲線；每段獨立。 | 不叫「補間」「ease」。 |
| 曲線編輯器 | curve editor | 編輯緩動與數值曲線的進階面板。 | — |
| 錄製 | record | 開啟後改屬性才寫關鍵幀。 | — |
| 片段 | clip | 有自己時間軸的圖層：符號實例、Lottie、影片、影像序列。父時間軸上顯示為片段軌（起點 + 長度）。 | 不叫「剪輯」「影片」（影片是片段的一種來源）。 |
| 動畫段 | span | 圖層列上一段具名動畫的起訖條。 | — |

| 洋蔥皮 | onion skin | 前後幀半透明疊顯。 | — |
| 逐格 | cel | 逐格動畫：一個「格」= 一段時間內顯示的一張圖層內容；逐格群組、殘影。 | 不叫「幀動畫」。 |

| 錯開 | stagger | 多個圖層同一動畫依順序延遲。 | — |
| 描邊動畫 | stroke animation | 描繪出現／消失、行進虛線、描邊脈動。 | — |

### 2.6 狀態、互動、資料

| 中文 | 英文 | 定義 | 不要混用 |
|---|---|---|---|
| 狀態 | state | 圖層或符號的具名外觀集合。內建：一般、滑過、按下、焦點、勾選、停用；自訂狀態由 class 承載。 | 不叫「樣式狀態」「偽類」（偽類只在進階）。 |

## 4. 描述性解說（給新進者的一頁）

一個 **UI Project** 裝著一款遊戲的全部畫面。每個畫面是一個 **UI**，發佈後整個專案變成一份唯讀的 **Bundle**，遊戲只讀 Bundle。

打開一個 UI，中央是**畫布**：灰色**舞台**上放著**文件區**，文件區裡的每個東西都是一個**圖層**。圖層就是文件樹裡的一個元素，它的**名稱**就是程式呼叫它的 id，所以名稱要像變數名。圖層有**角色**：文字、圖片、向量、群組、堆疊、按鈕、實例、片段……角色決定圖示和屬性面板顯示哪些分組。**群組**裡的子圖層自由擺放，**堆疊**裡的子圖層自動排列。

把幾個圖層變成**符號**，就能在各處放**實例**；實例可以**覆寫**少數屬性，也可以**分離**回普通圖層。雙擊實例**進入編輯**它的定義，此時你在一個新的**範圍**裡。

**向量圖層**裡的東西叫**形狀**；形狀的幾何是**路徑**，路徑由**頂點**和**把手**構成。**修改器**非破壞式地改形狀（修圓、重複、位移），**造形指令**破壞式地合併或切割。「路徑」只指這種幾何；讓圖層沿著曲線跑的動畫叫**運動路徑**。

每個範圍可以有多條具名的**時間軸**（intro、idle、outro…）。時間軸裡，每個圖層的每個屬性是一條**軌道**，軌道上的點是**關鍵幀**，兩個關鍵幀之間的速度曲線叫**緩動**。有自己時間軸的圖層（實例、Lottie、影片）叫**片段**。時間用**幀**顯示，內部是秒。

圖層有**狀態**（一般、滑過、按下…），狀態之間的自動補間叫**過渡**。**觸發**用「當…執行…」把事件接到**動作**：切狀態、播時間軸、跳**標記**、發**音效提示**。圖層對程式開的資料口叫**連接點**，屬性可以**綁定**到連接點；更複雜的邏輯放進**流圖**，流圖由**節點**和**連線**組成。

**效果**是像素層的處理（投影、光暈、模糊），一個圖層上的效果依序排成**效果堆疊**；效果參數也能打關鍵幀。**3D 圖層**有位置、旋轉與**錨點**，透視屬於**3D 空間根**。

四種**模式**（設計、動畫、效果、展示）只換主面板與工具，資料是同一份。**設計變數**（顏色、字型、間距）與**主題**讓整個專案換皮；**素材**是專案裡的檔案；**契約**是給 AI 的工作規格。做好之後**發佈**成 Bundle，宿主用**熱重載**換新版本。
