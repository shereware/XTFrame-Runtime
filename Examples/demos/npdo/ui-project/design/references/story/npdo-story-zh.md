# NPDO 國有財產處置員：故事設定（原文整理）

作者提供的原始文案，只整理分段與條列，字句保留原文。英文版見 `npdo-story-en.md`。

## 1. 背景

國有財產署的職員，在政府要賣地、開發或是任何土地應用時負責處置土地。

今天的任務是前往勘查一座某個已解散法人承租的土地上，在 1991 年興建啟用、1997 年廢棄的地上物——一棟醫院，要決定如何處置這個地上物，以進行政策的土地活化利用開發。結果發生一連串可怕的事件。

## 2. 表設定

- 這間醫院由一個財團法人投資興建，引入高端的前沿設備與人員。
- 面積不大，由兩個互相連接的建築組成：
  - 以心臟外科聞名的**外科大樓**；
  - 主攻前沿的**內科暨心身醫學科大樓**。
- 在二十年前發生莫名其妙的挾持事件，受困者不知為何不多。在警察攻堅莫名失敗後，又在數名霹靂小組失蹤的情況下結束事件，從此就被封鎖。

## 3. 裏設定

- 這間醫院底下進行著某群人發現並將之宗教化的**生體能量**研究，目的是將這個理論科學化並帶到民眾視野中，由已將公司宗教化的企業家主持並投資。
- 雖然是這樣講，他們的目的卻不是將生體能量的原理與宗教脫鉤，而是**掌控**，由此派生的是在有明確結果作為參考而不顧過程的目標導向實驗，包含：
  - 從人抽取能量；
  - 向健康的身體灌輸能量；
  - 向生病的人灌注能量；
  - 向死體灌輸能量；
  - 從動物抽取能量；
  - 在手術的過程運用能量。
- 即使他們擁有在一定程度上運用生體能量的技術，卻刻意忽略了生體能量**為存活而生，因存活而在**的本質。

## 4. 故事

玩家前往醫院勘查，卻陷入被監禁的境地。這裡有：

- 因為對生命不敬的實驗而殘留的執念；
- 從密室中被釋放、心靈與肉體被扭曲的遺留怪物；
- 為探險闖入卻遭到同化融合的人；
- 與生體能量研究無關、原本就存在、被稱為鬼的靈魂。

玩家必須在這個惡劣的地方逃出生天。

## 5. 遊玩

### 遊玩 1

在醫院原本所做的機關、殘留著思考能力的個體，以及因時間而腐朽的環境中，玩家必須屏住呼吸、隱藏恐懼，並利用自己的機智閃躲遊蕩的怪物、解除機關，並在了解了這裡所發生的過去後活著離開這裡，並試圖帶人回來摧毀這個地方。

### 遊玩 2

那些充斥著不屬於自己的生命能量，腐朽而扭曲的東西太可怕了。什麼？你說生命能量來自生命的活動與意志？奮起吧！燃起怒火吧！在這個只剩下你真正活著的地方，你絕對不能怕鬼，鬼才要怕你！
